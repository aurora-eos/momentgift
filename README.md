# MomentGift

React + TypeScript + Vite + Phaser 3 + Tailwind CSS 像素互动贺卡。

## 本地运行

需要 Node.js 22 或更新版本。在此目录执行：

```powershell
npm install
npm run dev
```

打开终端显示的网址。`npm run build` 运行 TypeScript 检查并生成 dist；`npm run preview` 预览构建结果；`npm test` 检查三种主题中出生点、通路及全部交互点的可达性。

## 完整体验

- 设置普通 / 生日 / 新年主题、收发信人、祝福、问题、答案与钥匙藏处。
- 草稿自动保存到本设备；返回修改和刷新设置页会恢复。
- 完成设置即进入收信人预览。分享链接从花园入口重新开始。
- WASD / 方向键或屏幕方向按钮移动；E / 探索按钮互动。松开按钮、失焦或打开对话会停止移动。
- 路牌 → 长椅 → 书架 → 钥匙藏处，当前线索显示在画布上方。可跳过线索直接探索，不会卡关。
- 答错可重试，答对才拿到钥匙。支持忽略英文大小写、首尾空格及全半角差异。
- 普通模式浇花、生日点蜡烛、新年放烟花。主题互动可选，不阻挡主流程。
- 拿钥匙打开信箱 → 密封信封 → 点击拆信 → 贺卡展开与撒花。支持再次撒花和重新游玩。
- 对话框支持键盘焦点约束，普通探索文字可用 Enter / Escape 关闭。

## 分享 / 部署

静态网站构建命令 `npm install && npm run build`，输出目录 `dist`。源码仓库根目录应直接包含 package.json、index.html 和 src。

127.0.0.1 / localhost 地址仅本机访问。部署成功后，在公网网站设置贺卡并复制完整分享链接。链接编码了祝福和答案，属于趣味互动，不适合敏感信息和安全验证。

不包含数据库、登录或服务器。手机控件已实现，微信等实际设备兼容性仍需实机检查。

## 人物视角像素版（2026-10-28）

主场景现在是人物眼睛高度的受限透视视角，保持 360×270 低分辨率像素渲染。看不到整个地图，必须行走和转身观察。旧版平面场景仅用作地图。

- WASD / 方向键：相对视线前进、后退、左右平移。
- 拖动主画面：环顾，支持鼠标和触摸。

- E / 探索按钮：探索附近物品。
- 花园地图：展开原版运行地图，红箭头连续同步位置与视线方向。地图不暂停主游戏。

- `interactions.ts` 按物品足迹距离与观察方向排序，优先选择面前的物品。`PerspectiveGarden.canSee()` 根据实际视野投影与不透明实体射线检查遮挡。

### 声音

- `Soundscape.ts` 使用本地 Web Audio 合成轻柔环境与操作声；不下载音频，也不使用麦克风。进入花园或点击声音按钮之后才创建/恢复音频上下文。

- 抽屉/木门、纸张、钥匙、开锁、封口、展开祝福有不同的声音。按钮可关闭声音并记住偏好；标签页隐藏时暂停，离开游戏时释放音频资源。不支持音频的浏览器仍可继续游玩。
- 这些是程序合成的声音，不是现场录制的拟音。实际听感与设备音量还需在真实浏览器验收。
